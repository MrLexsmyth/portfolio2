Inventory Management
For an e-commerce app like **Lookgirly**, your admin dashboard is already covering the basics. Here are some valuable features you can add as the store grows:

### Inventory Management

```js
{
  name: "Inventory",
  icon: <Boxes size={20} />,
  path: "/admin/dashboard/inventory",
}
```

Features:

* Low-stock alerts
* Out-of-stock products
* Inventory history
* Bulk stock updates
